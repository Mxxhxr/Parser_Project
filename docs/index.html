Language Reference
Program Structure
program Name; var x : integer; begin { statements } end. Every program starts with program, declares variables in var, and wraps statements in begin...end.
Variables & Types
var a, b : integer; x : real; name : string; flag : boolean; Declare variables before begin. Types: integer, real, string, boolean.
x := 42; name := 'hello'; Assignment uses := (not =).
Output
write(x); writeln(x); writeln('hello ', name); write prints without newline; writeln appends one. Multiple args separated by commas.
Arithmetic
a + b a - b a * b a / b a div b a mod b div = integer division, mod = remainder, / = real division.
Conditionals
if x > 10 then writeln('big') else writeln('small'); Uses then keyword. For multiple statements use begin...end.
= > < >= <= Comparison operators. Equality is = (not ==).
Loops
while i <= 10 do begin writeln(i); i := i + 1 end; Uses do keyword. Body must be a single statement or begin...end.
Boolean Logic
a and b a or b not a Keywords, not symbols. Values: true, false.
Comments
{ this is a comment } Curly braces for comments (Pascal style).

▲ About This Project

What is this?

A custom compiler built from scratch in C++ for a Pascal/Perl-inspired language. It performs lexical analysis, parsing, and interpretation — converting source code into a token stream, validating grammar, and executing the program.

How it works

The C++ source is compiled to WebAssembly via Emscripten, so the actual compiler runs directly in your browser — no server. The editor uses Monaco (VS Code's engine) with a custom language definition for syntax highlighting and error markers.

What I built

Lexer (tokenizer), recursive-descent parser, AST evaluator, and a value system supporting integers, strings, and booleans. Error messages include line and column numbers for precise feedback.
